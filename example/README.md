# Face Recognition — Ionic example

</div>


Capacitor 6 + Ionic React demo for `face-recognition-capacitor`.


```bash
# from repo root
npm install && npm run build
cd example
npm install
npm run build && npx cap sync
npx cap open android   # or ios
```
